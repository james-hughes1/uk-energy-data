# Energy Grid Data & VPP Optimisation

A website that I'm building to learn more about the UK power grid. There will be multiple tabs on the website where I explore different aspects. One tab will have a dashboard of live UK power grid data, for instance the imbalance price and load. In another section, I will explore forecasting energy prices using quantile regression, as well as optimising a virtual power plant (VPP). The project goal is primarily learning so the direction might change as I build things out.

I will try to build the codebase using the following guidelines:
1. Keep the code clean and documented. Use the most appropriate linters and reformatters where applicable, keep the code readable, and add comments where they are needed to explain chunks of code.
2. Make the website visually pleasing to enable deeper understanding.
3. Include unit tests to ensure the code is robust.
4. Keep clear separations between different subprojects in terms of how the code is organised. But also separate code that is common to multiple/all subprojects. Different subprojects will be displayed on different pages of the website.
5. As the project is about learning about the subject, include explanations of the real world context/implications in the documentation and in the website itself, including explaining advanced data science/machine learning techniques used.
6. Adhere to "Conventional Commits", with the format "-type-: description" for commit messages accordingly.
